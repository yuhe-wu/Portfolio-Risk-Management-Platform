# Portfolio-Risk-Management-Platform
A python based portfolio risk management platform for portfolio analytics, VaR, Expected Shortfall, stress testing and risk report.

Current Features:
- Historical market data download
- Portfolio return calculation
- Annual growth rate (CAGR)
- Annualized volatility
- Sharpe ratio
- Wealth index (graph)
- Max drawdown (drawdown graph)
- Market context analysis
- 52W High/Low
- Position in range
- Price percentile
- Z-score

Planned Features:
- Historical VaR
- Expected shortfall
- Stress testing
- AI risk officer
